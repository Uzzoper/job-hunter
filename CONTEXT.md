# Job Hunter

Automated job search platform that scrapes junior-dev listings, analyzes them with AI, and generates personalized application emails.

## Language

**Job**:
A publicly listed position at a company, identified by its URL.
_Avoid_: Vacancy, posting, listing

**User**:
A registered person with authentication credentials (email + password).
_Avoid_: Candidate, applicant, account

**UserProfile**:
A user's career profile containing resume text, target skills, desired communication tone for generated emails, and personal projects.
_Avoid_: CV, resume (for the whole profile — resume is part of it)

**CompanyTone**:
The desired communication tone used when generating application emails — FORMAL, CASUAL, or STARTUP. This is a user preference, not inferred from the resume.
_Avoid_: Writing style, voice

**ResumeUpload**:
The act of sending a PDF file to the backend, which extracts text via Apache PDFBox, delegates skill/project extraction to AI, and saves/overwrites the user's profile.
_Avoid_: CV import, file attachment

**Project**:
A personal, academic, or professional work item that a user has built or contributed to, with a name, description, and tech stack.
_Avoid_: Portfolio item, experience, work sample

**Scraping**:
The automated process of fetching job listings from external websites.
_Avoid_: Crawling, harvesting

**JobAnalysis**:
The AI-generated evaluation of a job relative to a user's profile, with a match score, matched/missing skills, tone detection, and summary.

**EmailDraft**:
A personalized application email generated by AI for a specific job based on the user's profile.
_Avoid_: Application email, cover letter (it's not a cover letter — it's a tailored email body)
